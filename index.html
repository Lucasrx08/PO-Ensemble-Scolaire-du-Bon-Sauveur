Votre circuit

Comment visiter ?

Touchez le repère sur la photo ou le bouton Continuer pour passer à la vue suivante. Un clic correspond à une vraie vue du parcours, sans zoom intermédiaire.

Retour ramène à la vue précédente de votre circuit. Le menu permet de choisir une autre formation. Votre progression est conservée sur cet appareil si le navigateur l’autorise.

Les vues reprennent le parcours Genially existant. Les numéros indiquent des photos, pas un nombre de salles. Cette visite photo ne fournit pas de géolocalisation.
